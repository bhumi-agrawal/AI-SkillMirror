# AI SkillMirror

AI SkillMirror is an AI-powered career readiness and skill-gap
analysis platform for students.

## Problem

Students often do not know whether their current skills match
their desired career.

## Solution

AI SkillMirror analyzes a student's resume, compares detected
skills with career requirements, identifies skill gaps and
generates a personalized learning roadmap.

## Features

- Resume PDF analysis
- Skill detection
- Career readiness score
- Skill gap detection
- Skill visualization
- Personalized roadmap
- What-if career simulator

## Technology

- Python
- Streamlit
- Pandas
- Plotly
- PyPDF
- Scikit-learn
